# 🚗 Drive Motors - Car Dealership Website

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)  
🔗 [Live Site on GitHub Pages](https://faustinmulinge.github.io/drive-motors/)

Drive Motors is a simple client-side car dealership website that allows car dealers to add vehicle listings and customers to view them. Built using **HTML**, **CSS**, and **JavaScript**, the platform leverages **localStorage** to simulate persistent data without a backend.


## 🚀 Features

- Add a new car with details (make, model, price, transmission, dealer info).
- View a list of available cars.
- Contact a dealer via phone.
- Remove a listing (for demo/demo cleanup).
- Responsive layout.

## 🧠 Technologies Used

- HTML
- CSS
- JavaScript
- localStorage API  

## 🔧 How to Use

1. Open `addacar.html` in a browser and fill out the car details.
2. Submit the form — the car will be stored in `localStorage`.
3. Open `availablecars.html` to view and interact with the list of cars.

## 🌐 Deploying to GitHub Pages

To deploy the site on GitHub Pages:

1. Push your project to a **public GitHub repository**.
2. Go to the repository on GitHub.
3. Click on **Settings** > **Pages** (or “Pages” from the sidebar).
4. Under **Source**, choose the branch (usually `main`) and select `/ (root)` as the folder.
5. Click **Save**.
6. Your site will be published at:  
   `https://faustinmulinge.github.io/drive-motors/`

Make sure that `index.html` is in the root of the repository.
